# Cloth runtime observations — 2026-10-29

Observed with native accessibility and screenshots through CUA on Cloth 0.1.0 build 12. These are UI observations, not captures of executed remote processing.

## Reachable workflows

- Create: file chooser, drag/drop affordance, link entry. Link entry pre-populates clipboard contents; cancelled without downloading.
- Settings: 0 of 300 Setapp AI credits remain. Disclosure names ElevenLabs Scribe v2 transcription, OpenAI GPT-5 mini moment selection; audio and transcript transmitted, video/framing/speaker detection local.
- Settings controls: burn subtitles; recognise speakers; speaker-colored captions; cut pauses/filler sounds; reveal exports in Finder; completion sound; output folder; global editorial prompt; diagnostic log export advertised as excluding keys/links/transcripts; onboarding replay; acknowledgements.
- Library contains a bundled example, with run title/date/count/source duration; rename, run again, reveal, delete; transcript expand/copy/text export; source URL copy/open.
- Example clip editor: individual sentence inclusion, per-sentence speaker reassignment, swap speakers, duration/count summary, close, re-cut disabled until changes.
- Run again opens configuration without processing: Auto/Manual, source replacement, output folder, clip count, 15–30 / 30–60 / 60–90 / custom duration, per-run prompt, caption bottom/top/off, quality Standard/Sharp/Maximum, generation button.

## Boundaries

No generation, paid API calls, original clip changes, deletion, credential use, or preference changes were performed. Paid paths are unavailable at the observed credit balance. The example established reachable controls and data presentation, not the behavior of a fresh AI run. No private user videos were inspected.
